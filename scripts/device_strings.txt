# zcode-pet ESP32 设备端闭集文案（唯一来源）
#
# 分两节：
#   # sync:   同步区——与桌面 daemon/main.swift 的 update()（原 1528-1550 行）全部 12 条
#             合成文案逐条对应的「去 emoji 投影」（mid 1-11 与 15）。桌面文案改动必须
#             同步此区，scripts/check_esp32_bridge.sh 的桌面同步断言仅对此区生效。
#   # device: 设备区——设备专属 UI 文案（mid 12/13/14/16、清单浮层、顶栏模板、About 页、
#             BLE 诊断等），无桌面来源，不受同步断言约束，但同样进字体子集。
#
# 语法：<key> = <text>。key 为数字（=协议 mid）或大写下划线符号名（固件引用）。
# 模板 {n}/%d 由状态帧里的 n 参数填入（设备端 snprintf，数字走 Montserrat fallback；
# 单个 % 结尾会被生成器转义为 %%，printf 落成字面 %）。
# 全文（两节）所有码点进 lv_font_conv 字体子集——新增文案必须重跑 gen_device_assets.sh
# （产物之一 assets/fonts/zcp_font_16.codepoints.txt 是 build_pet.sh 覆盖检查的基准）。
# 禁止 emoji（思源黑体系字体无 emoji 字形）；字符白名单见 check_esp32_bridge.sh。
